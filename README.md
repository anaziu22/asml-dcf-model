# ASML Holding NV - DCF Valaution Model

A full DCF valuation of ASML Holding NV built in Python using 2024 actual financials.

## What this model includes 
- Revenue projections 2024-2028
- EBITDA and free cash flow projections
- DCF valuation with sensitivity analysis
- Comparable company analysis (EV/EBITDA)

## Key findings
DCF Implied Price: € 273-414 across sensitivity range 
Market Price at this time of model: €738.12 
ASML trades at 6.0x EV/EBITDA on 2026 estimates vs peer median 15.4x

## Tools used
- Pyhton (numpy, pandas, matplotlib)
- Data source: ASML 2024 Annual Report
